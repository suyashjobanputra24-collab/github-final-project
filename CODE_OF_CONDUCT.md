# Code of Conduct

## Our Pledge
We pledge to make participation in our project a welcoming and respectful experience for everyone.

## Our Standards
- Be respectful and considerate.
- Use inclusive language.
- Accept constructive feedback.
- Focus on what is best for the community.

## Enforcement Responsibilities
Project maintainers are responsible for clarifying and enforcing these standards.

## Scope
This Code of Conduct applies to all project spaces and public interactions related to the project.

## Enforcement
Unacceptable behavior may result in a warning, temporary restriction, or removal from the project community.

## Enforcement Guidelines
Maintainers will review reports fairly and take appropriate action based on the circumstances.

## Attribution
This Code of Conduct is adapted from common open-source community guidelines.
